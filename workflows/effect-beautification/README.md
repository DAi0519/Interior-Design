核心保持源图：输入 bicubic 等比装入1920×1920（`always`，小图也会放大），右/下补到16倍数，原图参考 latent 和空 latent，Euler/CFG1，空默认负向；出图后按 ab 匹配源图色度，保留生成亮度，再按预设处理亮度/色温，裁掉右下补边。

工作台适配：保留现有1K/2K输出档及4K/6K的SeedVR2超分选择。裁去补边后先bicubic到工作台目标宽高，4K/6K继续既有无Prompt超分，再由唯一SaveImage输出PNG。因此输出档改变交付尺寸，核心推理始终长边1920；这与源MaaS画布“还原输入原尺寸、JPEG80输出”有意不同。输入继续工作台参考图安全合同，源MaaS的496–4000像素范围不是工作台新增准入限制。

主工作台和Beta经同一美化应用服务路由。独立飞书Prompt表继续作为正文真源；只对Flux补齐一次`zhiganEnhance, `触发词，OneAPI仍使用原正文。默认负向改为空，自定义负向仍整段覆盖；CFG1下负向是否影响画面不能从参数存在推断。实际送模正文、预设、步数、LoRA、后处理、真实推理宽高、来源SHA/参数策略ID和版本进入原有生成参数JSON，Beta复用现有Prompt/工作流版本字段，不新增模型或飞书枚举。
