# 效果图美化 Prompt v3 候选

2026-10-23 对照飞书当前美化 v2 与氛围转换 v13 编写。六段完整候选正文在 `Prompt-v3-candidate.json`，仍保持 `LOW/HIGH × NATURAL/WARM/COOL` 原结构，可由现有读取器直接校验。**这是本地待测候选，未上架、未替换在线 v2，未调用 GPU。**

## 借鉴与调整

| 方面 | v2 现状与风险判断 | v3 候选 |
| --- | --- | --- |
| 目标 | 零散光照/质感关键词 | 固定为保留原设计的室内摄影质感修整 |
| 场景保持 | 主要要求保持材质颜色和纹理 | 借鉴v13的Source Lock，补齐机位、透视、构图、比例、洞口、柜体、家具陈设与位置 |
| 光照 | uniform diffuse light可能抹平已有方向光和阴影 | 保持源时段、天气、内外亮度比、光向、阴影与灯具状态，只改善已有光照的物理表现 |
| 窗边/暗部 | overexposure of window shadows将两个目标混在一起 | 分开约束亮窗高光过渡和暗部已有细节，局部调整、不抬黑、不漂白 |
| 材质 | 缺少对finish/反射改善边界的说明 | 只改善已有粗糙度、反射和表面细节的渲染表现，禁止改变finish或添加纹理图案 |
| 强度 | 高强度的spatial depth没有明确几何边界 | 低档轻微局部修整；高档增强局部明暗分离、接触关系和已有材质细节，保持整体曝光与形状 |
| 色调 | 固定4000K/4800K/5000K相对不同原图未必对应稳定暖冷 | 自然保持源白平衡；暖冷使用克制的照明倾向，保护材质色相关系，避免黄橙/蓝青泛色 |

这里借鉴的是氛围转换的场景与光影约束，没有引入TIME/WEATHER转换分支。已有六套LoRA/步数/颜色匹配/后处理参数继续作为强度与色调执行基础；候选正文对暖冷保持克制，以降低与后调色叠加的风险。

## 验证与评估

已通过现有 `parseEffectBeautificationPrompt` 六段完整结构验证。对同一图、同一seed、相同预设分别构建v2/v3执行图，6/6均仅正向 `CLIPTextEncode.text` 变化；LoRA、步数、负向、颜色匹配、后处理、尺寸和产物合同未改变。Flux运行时仍只补一次`zhiganEnhance`，JSON内不保存该触发词，以兼容OneAPI正文。静态校验与独立文本审阅结果见 `Prompt-v3-candidate-validation.json`。

建议先对低自然/高自然做同图同种子A/B，确认机位/几何/物件/材质底色保持，原时段/整体曝光保持，以及材质和局部光影是否实际改善；随后核查暖冷与后处理叠加。覆盖日景、暗景/夜景、原图偏暖/偏冷及高反射/布艺/木纹等样本。每对只改变正文，不同时调整LoRA或调色参数。当前不宣称候选画质优于v2。
