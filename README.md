# Canvas Lab

团队内部的 AI 生图与效果评测工作台，在本机运行，通过飞书管理 Prompt、样本和结果。

## 功能

- **生图工作台**：白模渲染、空房设计、风格转换、精模渲染、效果图美化、效果图氛围转换、全景图美化、图片超分、AI扩图、风格反推与自由生图。
- **Beta 跑图**：复用样本集批量运行十类出图功能，包含风格转换、全景图美化、AI扩图与AI超分；对比多个模型或工作流，结果归档到独立飞书跑图明细。
- **模型评测**：围绕模型或 Prompt 制定对比实验，进行评分与结果分析。

在 **AI编辑 → 遮罩填充** 可上传原图、涂抹编辑区域，选择提示词填充或参考图填充后点击START。Flux2模式的推理档位为2K/4K/原图，默认2K；输出保持原图比例、长边最高2048px且小图不放大，支持单张结果下载；该模式不依赖OneAPI，生成前检查飞书字段，完成后归档原图、遮罩、填充参考图与结果，并显示同步状态及记录链接。新增模式、推理尺寸、扩展像素和工作流版本列。GPT Image 2.5 Sunburst 另支持蓝色矩形“框选”和自由轮廓“圈选”（松开闭合），两者不上传mask，使用OneAPI原生异步任务（返回ID后轮询），默认1K/medium并交付模型完整PNG；透明mask涂抹仍走同步编辑；三类区域分别保留，按当前工具提交。详见[遮罩填充测试说明](docs/image-mask-fill.md)。

生图工作台左侧由分隔线拖动控制两段收缩：向左拖时，144px功能目录先连续缩至80px，参数区再随宽度重排；向右拖按相反顺序展开，无需收起按钮。总宽304px以上可停留并记住任意中间宽度，窄栏中的字段、模型和上传信息按实际空间换行；收到仅剩80px功能目录时隐藏START。双击分隔线恢复默认宽度。900px以下改用“功能与配置”抽屉，功能可搜索，START保留在抽屉底部；收放保留原图、参数和任务状态。

**Banana 2.1** 已作为独立模型加入生图、Beta 跑图与模型评测，旧 Banana 2 保留。参数提供十四种画幅与 1K/2K/4K；不提供 512 或 2:1 全景。Beta 飞书跑图明细的“出图模型”和“Prompt融合”均使用彩色单选标签，分别记录出图模型与提示词模型。

在 **AI设计 → 风格转换** 上传一张空间图，明确选择现有平台风格，或上传一张风格参考图；可补充转换要求。未指定风格时不能开始转换。参考图只用于提取风格，原空间的结构、视角与布局保持不变。Prompt 版本、所选风格、主图、参考图及结果沿用飞书生成记录归档。

在 **AI编辑 → 图片超分** 可选择默认攸行3B、原有1MP/0.75MP两套7B、拆分版7B，以及 **KS版 · 7B** 和 **KS直入 · 7B**。普通四套提供4K/6K/8K；两套KS提供 **原图2倍／4K／6K**，4K/6K以长边4096/6144px为目标，保持原图比例。两套KS在这三个档位全部使用一次整图推理，模型内部16px补齐后的面积严格低于20MP；超限时先等比缩小推理，完成后插值恢复所选成品尺寸，分别记录推理尺寸与交付尺寸。KS仅对全图做一次0.75MP预处理，KS直入不做该预缩放，输入每轴仍需384–3200px。最终PNG须精确匹配目标；恢复后的6K不冒充原生6K AI推理。目标尺寸与实际PNG尺寸分开记录，实际画质和耗时需分别实跑比较，详见[输出尺寸说明](docs/image-upscale-output-size.md)。**AI扩图** 也归入AI编辑，固定2K输出，默认原比例，保留模型、五个画幅预设和拖动缩放构图，不提供分辨率选项。

生图工作台与 Beta 跑图的模型选择默认显示已选摘要，点击展开同宽列表，可搜索、全选或取消全选可用模型，选中显示黑底白字和橙色小勾，取消时至少保留首选；选择即时生效，不设模型数量上限；每个模型各生成一张，按两路并发排队。单模型生成仍可选择 1–4 张。风格选择使用同款可搜索下拉，保持单选及原有智能默认/参考图规则。

在 **Beta跑图 → AI扩图** 可直接选择飞书已有图片样本集（包括其他功能创建的样本集），无需重新上传；新建样本集仍归当前功能。可多选 **Flux Fill OneReward / Flux Fill Dev / Qwen Image Edit 2511 / Sunburst**，对同批样本比较不同工作流。整批共用原比例或五个预设画幅、1.5/2/3倍及居中构图，固定2K；每个样本分别运行所有已选工作流，不可用项显示原因并阻断。扩图选择与普通模型参数独立保存，结果只写Beta飞书跑图明细，并沿用生成/同步双进度。实际效果需运行后逐图检查。

在 **Beta跑图 → AI超分** 可复用已有图片样本集，多选六套SeedVR2工作流同图对比，默认攸行3B。输出尺寸取所选工作流支持项的交集：只选KS可用原图2倍/4K/6K，只选普通四套可用4K/6K/8K，混选可用4K/6K；整批按同一所选尺寸运行。两套KS输入每轴仍需384–3200px，2X/4K/6K全部使用20MP以下整图推理预算。工作流与尺寸独立记忆，无需OneAPI连接；结果仅归档Beta飞书跑图明细，保留原图、结果、实际尺寸、工作流版本与参数，沿用生成/同步双进度及仅失败项重试，新KS任务冻结26.3版本，异常不自动重复提交GPU；旧20.1/21.1/26.1和26.2已有结果继续按原冻结合同恢复归档。

## 快速启动

需要 **Windows / macOS、Node.js 24+**，以及仓库和对应飞书 Base 的访问权限。

从 [Releases](https://github.com/DAi0519/Interior-Design/releases) 下载 `canvas-lab-v*.zip`，解压后双击：

- macOS：`start-macos.command`（首次被拦截时，右键选择“打开”）。
- Windows：`start-windows.cmd`。

启动器会自动安装依赖、引导首次飞书初始化并打开工作台。

也可在项目目录执行下列命令；`npm run lark:init` 仅首次初始化飞书 CLI 时需要：

```bash
npm ci
npm run lark:init
npm start
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)，在“连接中心”完成飞书授权，按需填写自己的 OneAPI Key。

Flux 和图片超分需要能访问公司 ComfyUI 服务；自定义地址、端口和飞书资源配置见 [.env.example](.env.example)。

OneAPI Key 默认只保存在内存，选择“记住在这台电脑”后才写入 `.env.local`；请勿提交本机配置或密钥。关闭启动终端会停止服务，请先等待生成与飞书同步完成。

## 检查更新

三个工作台顶栏都有版本与更新入口。打开页面后会自动检查正式 Release，页面可见时每 30 分钟再次检查；有新版时显示提示，点击入口可查看更新说明，点击「下载安装」下载、校验并安装官方运行包。

从 Release ZIP 解压的运行目录支持**原地更新**：与同版本官方 `.sha256` 文件比对后，替换程序文件，保留 `.env.local`、本地数据和目录路径；失败时恢复旧程序。生成、评测或飞书同步未结束时会阻止安装。成功后关闭原服务，再双击原目录的启动脚本，新版依赖会按锁文件自动安装。

带 `.git` 的源码工作区采用**新目录安装**，默认放到当前项目旁的 `canvas-lab-v<version>`，可用 `.env.local` 的 `INSTALL_BASE_DIR` 指定父目录；已有目录不会覆盖。完成后手动复制 `.env.local` 到新目录，再运行新版启动脚本。

仓库已公开，更新检测无需 GitHub 登录或额外 Token。公开接口限流或暂时不可用时，会通过公开版本页及标准 ZIP 地址再次核验；仍无法取得合格发布包时显示“暂时无法检查”，可打开 [Releases](https://github.com/DAi0519/Interior-Design/releases) 手动查看。

更新前先等待生成和飞书同步完成。飞书登录由本机 CLI 管理，无需重新授权。确认新版运行正常后再处理旧目录。

### 多角度编辑

在生图工作台的 **AI编辑 → 多角度** 上传一张原图，拖动右侧摄影机球，或使用左侧方位/水平/垂直/特写·标准·远景控件，点击 START。可在机位预览和生成结果之间切换，后台任务按功能恢复，结果可下载，并同步飞书生图记录。输入最高20MB、6400万像素、单边16384px；大图压到长边最高2048、8px对齐后直接推理，小图不放大。水平角度以原视角为0°，90°为右侧、180°为后方、270°为左侧；后半圈会补充绕主体移动及背面拍摄指令。角度是模型编辑意图，不保证精确三维机位，未知区域和房间布局可能被重绘，实际效果以出图为准。工作流能力随当前ComfyUI配置检测，不依赖独立4175测试服务。

多角度三方接入：AI编辑→多角度提供Qwen、Banana 2.1和Sunburst单选；默认Qwen，模型与机位随任务冻结，换Key重新读取权限，失效选项阻断且不自动换模。Qwen沿用原尺寸最高2K直接推理；三方原图同样压至长边最高2048，按模型目录选择最接近原图比例的合法2K画幅，实际返回图超过2048时仅等比缩小，不裁剪或后置超分。保留模型原生尺寸、请求尺寸、交付尺寸和产物摘要，不宣称三方原生尺寸等于交付尺寸。三方使用既有OneAPI通道（Banana Responses、Sunburst edits），不重试收费提交；均同步飞书生图记录，不发布MaaS策略。角度为生成意图，准确背面与空间一致性需另做质量评测。

多角度归档与反打：统一START前校验飞书Schema，复用参考图/结果图/最终Prompt/生图模型/尺寸/耗时/生成参数，功能标记多角度；新增水平角度（°）、俯仰角度（°）、景别、镜头指令版本四列。实际提交Prompt在执行前冻结并原样归档，原图保留上传原件，生成参数记录预处理/模型原生/交付尺寸、模型身份和机位。结果卡呈现同步中/成功/失败及飞书记录链接，失败不伪装成功。后半圈使用以原摄影机为参照的反打描述：从原图远处移动到场景另一侧，朝原拍摄点回看；若原图面向窗户则背靠窗户向室内拍。未见空间仍由模型推断，不承诺几何角度精确或真实复原。
