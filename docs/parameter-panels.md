# 参数面板展示规则

桌面共享导航侧栏在 144px 与 52px 间收展。生图参数栏独立拖动，展开可停在 224–476px 之间，宽度小于 224px 时仅在拖动中预览。松手按 112px 中点吸附到收起或最小可读宽度。旧宽度偏好按原来包含 144px 目录的数值读取，关闭的参数区和 START 不接收焦点。

打开或刷新生图工作台时，桌面参数栏默认展开并恢复上次保存的宽度。参数栏与画布交界处的短线把手可点击或按 Enter 收展，也可横向拖动调宽。收起留在当前页面，短线贴在画布左边缘。工作台铺满浏览器视口，结果区使用目录和参数之外的可用空间，嵌入画布与外壳使用直角相接。右侧直接显示内容，原图、标注或结果之间的切换由独立图标操作承载。窄屏由顶栏菜单打开导航侧栏，并将「查找功能」和「参数配置」并排放在画布上方，当前功能只在顶栏显示，参数仍使用原生抽屉和原有表单。

主工作台 AI 渲染组统一使用上述栏位。渲染台、平面机位和添加人物/宠物虽有独立结果或画布，仍将原参数和 START 节点挂入主配置栏。切换入口后只有当前栏位可见和可操作；共享下拉、主执行状态和可用性错误随原控件保留。

首页对话的「选择功能」复用工作台目录。自由生图和无需操作画布的生图、渲染及超分功能可在对话中执行。顶部保留选择功能和全部参数。选中功能后，常用项仍在提示词下方的底栏，并在各自按钮旁直接打开非模态下拉。房型单选后收起，「其他」保留原输入，家具可在同一层连续多选，风格和模型使用原搜索下拉。画幅、分辨率和张数仍在输入框工具栏。原设置里的 Agent、版本、质量、噪声等低频项由「全部参数」按需呈现。从首页对话选择标注、构图或风格反推时，原画布与表单挂入同一对话，不切换地址。模型、画幅、模板、机位或模式等参数通过对话工具栏映射回原控件。独立入口继续提供原工作区。所有入口复用原校验与提交，退出时归还表单节点和已有值。

必传原图、编辑指令和当前模式的关键参考图可以直接在对话框内操作。共享发送键按原表单校验，缺少输入时在对应动作旁显示原因。纯图片流程只显示适用的参数和动作。户型布局、渲染台、人物宠物的上传沿用原工作区的文件校验与换图，现有补充要求放入对话正文。桌面并排显示画幅、分辨率和张数。手机底栏用一项显示当前规格，点按展开原字段。房型、家具等功能快捷项放在操作栏上一行。人物宠物保留数量入口，出图规格从底栏「参数」打开。

多角度、AI 扩图、二次编辑、打光、平面图机位渲染、户型平面布局、AI 渲染台和添加人物或宠物共用输入框上沿的画布面板，在有效上传或恢复原任务后展开。按钮固定在输入框上沿，点按或按 Enter 收展，Esc 收起并归还焦点。面板与输入框同宽，收起仍保留原画布、标注和 iframe。过渡可反向，遵从系统减少动态效果设置。短横屏可纵向滚动画布和输入区。普通生图结果与风格反推继续使用对话消息。

「全部参数」共用固定表头与可滚动正文。桌面分组沿 16px 左右内距对齐，上下各留 12px。24px 标题行到同组内容留 8px，字段标签到控件留 6px。画幅、分辨率和张数直接以紧凑规格行呈现，标签在左、值在右，分组名称仅供辅助技术读取。仅展示当前可调的规格，全部固定时收起整组和分隔线。功能设置沿用共享选择器，常规字段和标题操作桌面使用至少 40px 的命中高度，触屏至少 44px。相关刷新放在分组标题旁。可移除的上传图复用对话 48px 缩略图和对齐右上圆弧中点的 16px 删除角标。配置错误完整换行，遮罩只覆盖工作区。

机位底栏缩略图用于更换平面图。空间与风格或直出提示词随模式入框，桌面快捷下拉统一放在底栏，手机把机位快捷项并入「参数」。每个模型的张数说明与字段名相邻，多模型时在同一字段显示本批总数。配置刷新放在「生成设置」标题右侧，任务待确认时「检查现有任务」回到生成动作区。提示词区域至少 88px 高，按钮和机位控制保留 44px 命中区。

AI 渲染单图上传以效果图美化为基准。分区使用 `.panel-section`，标题行使用 `.section-heading`、`.optional` 和 `.micro-status`。空态使用 `.reference-drop-zone`，图标、操作文案与格式容量提示直属网格，图标引用 `reference-upload-icons.svg#upload`。确认图片可用后，计数从“0 / 1”更新为“1 / 1”；可移除的参考图清空后恢复“0 / 1”。使用原位预览的上传槽共用缩略图样式，有独立预览卡的上传槽继续由对应控制器管理替换与移除。间距和字号见[项目设计规范](../DESIGN.md#工作台适配)的单图上传约定。

`public/panel-copy.css`集中维护展示策略。普通`.compact-config-note`按说明文案处理；真正的配置、权限、节点、尺寸或输入错误通过`.error`保留。控制器若复用同一节点呈现说明和错误，应在正常状态清空或隐藏说明，在异常时明确设置错误状态，恢复后移除；不要把DOM引用删断而导致错误分支失效。

超分和扩图仅在实际不可用时显示原因，不显示正常工作流解释或重绘免责声明。精模Prompt、白模风格、Agent及风格反推的配置失败仍需可见，错误全文换行显示。会改变当前执行含义的历史恢复异常和参数差异继续作为状态呈现。

桌面功能标题、参数表头、分区和 START 共用 16px 内距。移动参数抽屉的筛选器、分区和动作也使用同一内距。精模光影与参考图的内层分区沿用这一基线。窄栏渲染方式单列显示，避免长选项被挤掉。上传区和光影入口沿用原有交互。

上传框内部的格式/容量限制、画布操作状态与右侧结果信息不属于本次说明清理范围；不能为隐藏参数说明而隐藏这些区域或真实错误。被移除的运营入口仍可从相应功能文档中的飞书链接维护资产。
