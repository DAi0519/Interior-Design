# 参数面板展示规则

Main与Beta参数区移除控件外常态说明小字及飞书维护、查看提示词等运营链接。字段/选项名、必填/可选、计数、版本、可用状态及各功能必要操作保留；精模光影不设清除按钮。

`public/panel-copy.css`集中维护展示策略。普通`.compact-config-note`按说明文案处理；真正的配置、权限、节点、尺寸或输入错误通过`.error`保留。控制器若复用同一节点呈现说明和错误，应在正常状态清空或隐藏说明，在异常时明确设置错误状态，恢复后移除；不要把DOM引用删断而导致错误分支失效。

超分和扩图仅在实际不可用时显示原因，不显示正常工作流解释或重绘免责声明。精模Prompt、白模风格、Agent及风格反推的配置失败仍需可见。会改变当前执行含义的历史恢复异常和参数差异继续作为状态呈现。

上传框内部的格式/容量限制、画布操作状态与右侧结果信息不属于本次说明清理范围；不能为隐藏参数说明而隐藏这些区域或真实错误。被移除的运营入口仍可从相应功能文档中的飞书链接维护资产。

精模光影默认收起为缩略图＋名称入口，参数栏内展开三列卡片，选卡自动收起；渲染方式在面板外，无清除按钮或选中高亮框。选预设可直接上传，成功才切reference并关/锁模板，取消/非法保留预设；删图回未选解锁，不恢复旧预设。常显卡片、clear和双向禁止只留历史。见[精模说明](refined-rendering.md)与[光影库](refined-lighting-library.md)。

来源版本合同不变：纯词显示基础，图文/上传只读迁移v3且不依赖base，真实错误保留。本轮1397/1397通过，Main4192实测收起/选卡/无清除、面板外渲染方式、预设可上传、上传锁模板/删图未选解锁、无效文件保留预设及Escape归焦。见`outputs/refined-lighting-collapsible-panel-20261027/ui-validation.json`与`selected.png`、`expanded.png`、`upload-locked.png`。Beta仅自动化，未点START或改飞书；1394与旧UI仅作历史。

本轮最终完整`npm test`1366/1366通过；4192实测15个主功能面板，常态说明和维护链接可见数均为0，证据见`outputs/panel-copy-inline-cards-20261027/qa.json`。机械检查降级为HTML正则，保留两处既有动态img警告，没有新增可见坏图，不声称零问题。旧下拉布局或并排入口截图仅保留为历史，不代替当前卡片验证；本次未调用真实图像模型。
