# 参数面板展示规则

2026-11-02：桌面功能目录固定144px，不再缩成80px或替换短名称。仅参数配置栏参与拖动，可完全收起；总宽368px以上连续停留，较窄尾段松手吸附为368px可读展开或144px纯功能栏。旧窄栏偏好在加载时迁移；关闭的参数区和START不接收焦点，功能切换和分隔线仍可操作。900px及以下继续使用保留原DOM的配置抽屉。

主工作台 AI 渲染组统一使用上述栏位。渲染台、平面机位和添加人物/宠物虽有独立结果或画布，仍将原参数和 START 节点挂入主配置栏。切换入口后只有当前栏位可见和可操作；共享下拉、主执行状态和可用性错误随原控件保留。

AI 渲染单图上传以效果图美化为基准。分区使用 `.panel-section`，标题行使用 `.section-heading`、`.optional` 和 `.micro-status`。空态使用 `.reference-drop-zone`，图标、操作文案与格式容量提示直属网格，图标引用 `reference-upload-icons.svg#upload`。确认图片可用后，计数从“0 / 1”更新为“1 / 1”；可移除的参考图清空后恢复“0 / 1”。使用原位预览的上传槽共用缩略图样式，有独立预览卡的上传槽继续由对应控制器管理替换与移除。间距和字号见[项目设计规范](../DESIGN.md#工作台适配)的单图上传约定。

2026-10-30：精模三种渲染方式统一正常字重与选中小勾，标题仅显示“渲染方式”，不再附“已选几种”；多选、键盘、空选阻断和请求分流不变。白模渲染与精模渲染入口统一归入“AI渲染”。


Main与Beta参数区移除控件外常态说明小字及飞书维护、查看提示词等运营链接。字段/选项名、必填/可选、计数、版本、可用状态及各功能必要操作保留；精模光影不设清除按钮。

2026-10-29统一光影选择：精模、全景与光影转换复用12px正常字重单行入口和44px缩略图；单选显示名称，多选仅显示“N 种光影”，完整名称保留在悬停提示中。图卡名称11px正常字重，选中以右上角16px黑底白勾表达，不追加“已选”、不加粗名称或绘制整卡高亮框。默认三列，参数容器不超过280px或窗口不超过380px时统一两列；键盘焦点保持可见。

全景删除重复数量摘要和多选名称列表，把“清空”并入标题动作行，清空后保留光影要求；精模不新增清除入口。失效选择保留真实错误与生成阻断，版本/SHA不匹配的卡片不显示有效小勾，不因刷新静默删除草稿。Main/Beta及单选宿主的状态、上传互斥和请求合同不变。

`public/panel-copy.css`集中维护展示策略。普通`.compact-config-note`按说明文案处理；真正的配置、权限、节点、尺寸或输入错误通过`.error`保留。控制器若复用同一节点呈现说明和错误，应在正常状态清空或隐藏说明，在异常时明确设置错误状态，恢复后移除；不要把DOM引用删断而导致错误分支失效。

超分和扩图仅在实际不可用时显示原因，不显示正常工作流解释或重绘免责声明。精模Prompt、白模风格、Agent及风格反推的配置失败仍需可见，错误全文换行显示。会改变当前执行含义的历史恢复异常和参数差异继续作为状态呈现。

精模光影和参考图分区使用参数栏同一侧边距。参数内容宽度不超过 280px 时为 14px，缩到 250px 时为 12px。窄栏渲染方式单列显示，避免长选项被挤掉。上传区和光影入口沿用原有交互。

上传框内部的格式/容量限制、画布操作状态与右侧结果信息不属于本次说明清理范围；不能为隐藏参数说明而隐藏这些区域或真实错误。被移除的运营入口仍可从相应功能文档中的飞书链接维护资产。

精模光影默认收起为缩略图＋名称入口，参数栏内展开三列卡片，选卡自动收起；渲染方式在面板外，无清除按钮或选中高亮框。选预设可直接上传，成功才切reference并关/锁模板，取消/非法保留预设；删图回未选解锁，不恢复旧预设。常显卡片、clear和双向禁止只留历史。见[精模说明](refined-rendering.md)与[光影库](refined-lighting-library.md)。
