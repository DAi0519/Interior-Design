# 添加人物/宠物

从主工作台「AI 渲染 → 添加人物/宠物」独立入口上传已有场景图。普通生成结果、AI 渲染台和平面图机位渲染的结果区均不再提供「添加人物/宠物」快捷按钮。切换场景可继续使用现有的人物和宠物参考图。手动上传仅有图片时不补造原任务信息；历史任务已有的原渲染参数继续与本次编辑参数分开展示，来源交接协议保留兼容。

桌面参数侧栏、移动参数抽屉与对话「全部参数」共用原表单，由宿主正文滚动。侧栏用一个场景图入口显示添加动作和上传限制，上传后显示缩略图、文件名和换图提示。人数、宠物数并排，角色按需展开。位置与互动收起时只摘要已设置项，出图设置保留画幅和分辨率摘要。默认的「自动」可在下拉选项中查看。角色摘要呈现已选特征和参考图状态。模型配置刷新放在合成模型旁。角色参考图放在对应的首个角色内。数量归零时收起该类参考图，重新启用后复用已上传的参考图。普通下拉和 START 与 RUNNING… 复用工作台组件。详见[项目设计约定](../DESIGN.md)与[参数面板规则](parameter-panels.md)。

用户可配置总计 1 至 4 位人物和宠物。人物设置包括年龄、性别、地区、身形、发色和穿搭，宠物可指定种类、品种和特征。角色属性、位置和动作默认从常用选项选择，选择「自定义」时呈现文字输入。互动和可选参考图共同描述角色与场景的关系。人物参考图和宠物参考图可独立上传、替换和移除，每张绑定当前同类第一个主体。图像设置依据模型支持的画幅、分辨率和质量，自动画幅按场景图选取。场景和参考图各支持单帧 PNG、JPEG、WebP，最大 8 MiB、单边 4096 像素、16 MP，三图合计不超过 20 MiB。兼容的来源交接适用同一输入边界。

数量、角色特征（含「更多特征」）、位置与互动、出图设置各组内的选择器按内容宽度并排，空间不足自然换行。「位置与互动」和「出图设置」是同级入口，用通栏细线分隔。模型和刷新同组，画幅、分辨率与质量可并排。桌面菜单贴近触发按钮的右缘，上沿对齐，接近视口底部时向上避让。窄屏或触屏点按后在整组按钮下方展开。键盘也可打开，选中即收起菜单。选「自定义」后在组下方提供全宽输入。

送模顺序为场景原图、人物参考图、宠物参考图，未提供的参考槽位跳过。参考图只提供对应角色的身份特征。任务补入所选角色及匹配原照明所需的接触阴影和反射，尽量保留机位、空间结构、家具、材质和整体照明。原渲染参数用于查看和追溯，模型使用本次选择的出图设置。身份、互动、位置和画面保真为视觉验收项。

工作流 .4 直接使用通用短词。人和宠物同场时，默认让它们按图内环境自然互动。位置、动作和角色属性有值才追加。自动互动优先尊重已选动作，明确选择「各自活动」时按该设置执行。身份参考按实际图序各用一句，结尾要求保留原设计、机位和光照。送模前不做逐图分析或生成专场景描述。跨底图复用了相同默认词，已通过离线验证。

API 使用 `/api/scene-cast/config` 和 `/api/scene-cast/jobs`。新版参考图用 `referenceImages.person` 和 `referenceImages.pet` 传入，旧单参考参数仍可读取。提交前检查图片和模型权限。同一任务 ID 的相同输入复用任务，页面恢复只查询原 ID。任务在服务进程内保留，成图可下载，来源与本次参数分开展示。位置、动作、角色数量和属性进入实际提示词，回执逐图记录原件与送模的尺寸、字节数、顺序和摘要。原渲染提示词仅沿用来源接口已公开的内容和当前页面能够确认的用户原文。回执保留来源接口提供的版本、摘要和可见参数。

2026-11-17 首轮实图使用 GPT Image 2.5 Sunburst / 2K / medium / 自动画幅。同一人物和同一只狗各加入暖光卧室、自然光客厅一次。四个 OneAPI 调用均完成，原生 PNG、场景图和参考图的摘要、实际提示词与原渲染参数均以回执核验。卧室输出 2048×1152，客厅输出 3200×1968。人物和宠物均可辨认，位置、动作及主要设计保留通过本组视觉复核，细纹理、局部阴影或边缘存在轻微变化。网关回执合计 USD 0.117265。上述实图使用工作流 .1 自动互动，.2 的单主体与场景物件主动互动经离线验证。见[实图对照与原渲染参数](../outputs/scene-cast/report.html)。

2026-11-17 工作流 .3 同场互动复测使用相同四份输入原件及相同 GPT、分辨率、质量、自动画幅设置。两张场景各提交一次，双角色参考的原件与实际送模 SHA 和顺序、原渲染参数、实际提示词及原生 PNG 摘要均与回执匹配。人物和宠物在两个场景均可辨认，客厅轻摸肩背自然，小狗后身压到地毯边；卧室能看出凑近闻手，手背接触不明确且椅子遮挡后爪。主要家具、机位和光照方向保留，微小纹理、轮廓和局部阴影略有变化。网关回执合计 USD 0.083405。见[同场互动实图及参数](../outputs/scene-cast/mixed-interaction/report.html)。

2026-11-17 工作流 .4 默认短词实测沿用 .3 的底图、双参考原件及 GPT Image 2.5 Sunburst / 2K / medium / 自动画幅，两张各提交一次。角色属性、位置、动作留空并启用自动互动，实际送模正文逐字一致。两张人物和狗均可辨，自动选位后的抚摸动作更日常，但人物朝向让五官不如 .3 正面清楚。两张主要布局、机位和光照方向保留，卧室杯子移到人手里且杯碟未留，客厅茶几新增杯子和书。对比覆盖两种使用方式，每场景仅一张。实际送模词、输入 SHA、原生 PNG、原渲染与本次参数及费用回执已保存。见[默认词前后对照](../outputs/scene-cast/default-interaction/report.html)。
