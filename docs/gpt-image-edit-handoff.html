GPT 局部编辑接口交接表

模型：GPT Image 2.5 Sunburst　·　核对日期：2026-10-22　·　交接约定：1K／medium　·　参考实现：2026-10-22.sunburst.10

适用范围：业务后端接公司 OneAPI 的图像编辑接口。字段转换、圈选与遮罩、输入输出和统一提示词拼接方式均在下表。

模块交接项约定与示例
接口目标与范围GPT 图像编辑：原图＋用户指令＋可选物体参考图＋可选框选、自由圈选或涂抹，返回 1 张完整 PNG。提示词／参考图是内容模式，框选／圈选／涂抹是定位方式，两者自由组合。
业务输入模型、模式与指令maskFillModel: "gptImage25Sunburst"
maskFillMode: "prompt" | "reference"：提示词模式／参考图模式。
prompt：用户编辑指令，必填，去除首尾空白后 1–8000 字符。下面英文模板由后端拼接，不要求用户手写。
业务输入原图与参考图referenceImages: [原图描述]：必填且仅 1 张；这个字段虽然叫 referenceImages，装的是待编辑底图。
fillReferenceImage：参考图模式必填 1 张物体参考图；提示词模式不传。图2尺寸可与图1不同。

图片描述结构：

{
  "dataUrl": "data:image/png;base64,<图片Base64>",
  "name": "source.png",
  "type": "image/png",
  "size": 12345
}

size 是真实文件字节数，示例数字仅作结构说明；服务端仍需解码核验真实图片。

业务输入圈选区域（坐标示例）“圈选”按住拖动画轮廓，松开自动闭合；提交归一化轮廓点（0–1）：
{
  "editRegion": {
    "type": "polygon",
    "points": [
      { "x": 0.2, "y": 0.3 },
      { "x": 0.6, "y": 0.3 },
      { "x": 0.5, "y": 0.7 }
    ]
  }
}

矩形框选仍提交 editRegion: { x, y, width, height }。后端按实际轮廓在完整底图上画蓝线，作为第一个 input_image；不把轮廓转成外接矩形，不向 OneAPI 传 editRegion，不与 maskImage 同时提交。

业务输入涂抹遮罩 maskImagemaskImage：与方向归一后的原图同宽高的黑白 PNG，图片描述结构同上。白色＝编辑区，黑色＝保护意图，不能全黑。
maskExpand：0–256 整数，按原图像素扩展白区；提示词模式默认 10，参考图模式默认 80。无遮罩时有效值为 0。
业务输入输出档位与质量固定 1K／medium：outputResolution: "1K"，quality: "medium"。

后端按原图比例换算为实际输出宽高，传入上游 size。

定位区别蓝色圈选框选、画笔圈选、套索圈选统一使用蓝色线条圈出的区域，用于定位目标物体，具体操作由用户指令决定，可替换、移除、添加或修改。

把蓝色轮廓画进完整底图，使用同一圈选提示词；不因此生成或上传 mask。圈选边界不作为编辑的硬裁切范围。最终由模型去除全部圈选标记。

定位区别涂抹前端提交 maskImage → 后端先扩展白区，再生成同尺寸 RGBA PNG，alpha = 255 - red：alpha 0＝编辑，255＝保护意图 → 独立放入上游 mask.image_url。原图不叠加界面的灰白可视蒙版。mask 作用于图1，图2仍是物体参考。
图片处理图序与圈选标记图1是完整底图，圈选模式下带蓝色轮廓；图2是独立物体参考图。无 mask 时依次放入 input 消息中的第一个、第二个 input_image；涂抹同步请求仍对应 images[0]、images[1]。通过图片顺序＋提示词区分用途，不拼图。

原图／参考图转为PNG，保留未标记原件；蓝色轮廓仅用于送模副本。当前工作台示例颜色 #3b82f6，开发可使用自身的蓝色线条。不要把界面上的半透明可视蒙版当成独立的透明mask。

上游请求JSON 示例无 mask 的蓝色圈选＋参考图示例，3:2 原图、1K／medium。POST https://oneapi.qunhequnhe.com/v1/responses：
{
  "model": "gpt-image-2.5-sunburst",
  "background": true,
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [
        {
          "type": "input_text",
          "text": "<后端统一拼接后的完整Prompt，见下方统一拼接方式>"
        },
        {
          "type": "input_image",
          "image_url": "data:image/png;base64,<完整底图，已标记蓝色圈选轮廓>"
        },
        {
          "type": "input_image",
          "image_url": "data:image/png;base64,<物体参考图>"
        }
      ]
    }
  ],
  "tools": [
    {
      "type": "image_generation",
      "size": "1536x1024",
      "quality": "medium",
      "n": 1,
      "image_format": "png",
      "response_format": "b64_json"
    }
  ]
}

提交返回 202 与 resp_... 后，每 1.5 秒 GET /v1/responses/{id}，直到 completed；总等待 600 秒，不重复 POST。提示词模式省略第二个 input_image；纯指令仍传完整底图。业务字段不原样透传。

涂抹带独立透明 mask 时仍同步 POST /v1/images/edits，使用 images、mask、prompt、size、quality、n、output_format、response_format；不能向 Responses 添加 mask。

尺寸size 换算固定 1K，按原图比例选择输出尺寸：
1:1    1024x1024
3:2    1536x1024
2:3    1024x1536
3:4    768x1024
4:3    1024x768
16:9   1536x864
9:16   864x1536
21:9   1568x672
9:21   672x1568

其他比例按原图比例适配，输出宽高取16的倍数。

业务输入输入图片限制单张图片最大 4096 × 4096 像素，文件大小不超过 6 MiB。
上游输出返回结构与解析异步 completed 结果示例：
{
  "id": "resp_...",
  "status": "completed",
  "output": [
    {
      "type": "image_generation_call",
      "result": "<完整PNG的Base64或图片URL>"
    }
  ]
}

读取 output 中 image_generation_call.result（URL 或 Base64）。queued／in_progress 继续查询；failed／cancelled／incomplete 报错。本地超时不等于上游取消，不自动重发。

有 mask 的同步结果仍读取 data[0].b64_json，兼容 url／result；两条路径均交付完整 PNG。如有任务 ID、创建时间及真实费用则保留，缺失不伪造。

提示词统一拼接方式固定提示词＋用户提示词，由后端统一维护和拼接。调用方在业务字段 prompt 中只提交用户原文，图片、模式和区域仍按前述字段传入，不用维护六套提示词。
最终 prompt = 固定规则 + "\nUser instruction: " + 用户提示词 + "\n" + 固定输出要求

固定规则负责图1／图2身份、定位方式、透视光照与场景保持。后端根据是否有蓝色圈选、是否使用独立透明遮罩、是否传图2，自动补入对应约束；不需要额外调用模型编写提示词。

提示词完整拼接示例下面以蓝色圈选＋参考图为例，只有 {用户提示词} 替换成用户输入，其余为后端固定规则。其他场景沿用同一生成逻辑，按参数补约束。
Image 1 contains a selected region marked by a temporary blue outline of any shape. The outline is an annotation, not part of the scene. Use the selected region to identify the target object for the user instruction. Follow the requested action, including replacing, removing, adding or modifying the object. The selection identifies the target and is not a hard boundary for editing. Preserve the scene's composition, perspective and lighting, and keep unrelated objects and background unchanged. Remove all blue selection guide marks from the final image and restore the scene beneath them.
Image 2 is an object reference. If the user instruction calls for using the reference object, use the requested object from image 2 for the selected target in image 1, matching the scene's scale, perspective and lighting. Do not copy image 2's background.
User instruction: {用户提示词}
Return one complete image without blue selection outlines, guide marks, labels or a collage.
