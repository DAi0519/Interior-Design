# Seedream 5.5 接入

2026-11-19 初查当前 Key 目录为 118 款模型，网关只有 5.5 模板，尚无可调用路由。用户完成开通后，目录增至 119 款，已返回准确的 `doubao-seedream-5.5` 与上游 `doubao-seedream-5-5-261028`。工作台源码及归档接入已完成，两次真实请求验证文生图和图生图；只作连通性及单例改色验证，不代表全部画幅与场景质量已验收。

## 身份与请求

| 项目 | 值 |
| --- | --- |
| 工作台稳定 key | `seedream55` |
| 展示与归档名 | `Seedream 5.5` |
| OneAPI 调用 ID | `doubao-seedream-5.5` |
| 网关模板上游 ID | `doubao-seedream-5-5-261028` |
| 默认档位 | 4:3、2K、PNG |
| 文生图 | 复用 `generateImage` → `/images/generations` |
| 图生图 | 复用同一客户端 → `/responses` 的 `image_generation` 工具 |

每次只提交一张，不自动重试收费请求。PNG/JPEG 沿用现有客户端格式投影；不带 GPT 专属 quality 或 complexity。上游最多支持 10 张参考图，工作台继续沿用既有最多 4 张、单张 8 MB、合计 20 MB 的上传合同。

## 尺寸

5.5 使用独立矩阵，不能继承 5.0 Pro 的 2K 横竖尺寸。

| 画幅 | 1K | 2K |
| --- | --- | --- |
| 1:1 | 1024×1024 | 2048×2048 |
| 2:1 | 1440×720 | 2880×1440 |
| 3:4 | 864×1152 | 1776×2368 |
| 4:3 | 1152×864 | 2368×1776 |
| 16:9 | 1424×800 | 2816×1584 |
| 9:16 | 800×1424 | 1584×2816 |
| 3:2 | 1248×832 | 2496×1664 |
| 2:3 | 832×1248 | 1664×2496 |
| 21:9 | 1568×672 | 3136×1344 |

依据：[火山 Image generation API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh&redirect=1)、[Seedream 5.5 教程](https://docs.volcengine.com/docs/ark/seedream-5-5?lang=zh)。原生接口还提供 1.5K、透明图及图层能力，本轮只接 1K/2K 和普通图片。官方允许像素范围内自定义尺寸；网关单参考图 2:1 实测返回精确 1440×720 PNG，沙发改色生效，已追加 2:1 的 1K/2K 合法档位并允许原有全景链路使用，不继承 Pro 的实验 4K。2K及具体全景质量仍未实图验收。

## 接入范围

主工作台、Beta 和 Benchmark 复用共享目录。普通自由生图、白模、空房、旧房、风格转换、精模、光影转换、效果图美化、氛围转换、全景美化与质感增强沿用已有多模型链路。平面图机位按共享目录自动收录；设计实验室的布局动作及主/Beta 多角度补入现有白名单。各功能默认模型保持原选择，不用旧 Seedream ID 代替。布局、机位、多角度和 Benchmark 按当前 Key 目录准入并阻断失权；普通 Main/Beta 沿用既有生成链路与网关鉴权，不能据目录回读推断所有普通入口都有执行前权限守卫。

飞书主生成记录「生图模型」、Beta 明细「出图模型」追加 `Seedream 5.5`；Benchmark 配置「出图模型」追加 `Seedream 5.5 [doubao-seedream-5.5]`，横评表追加独立附件列。保留所有旧选项、字段、记录和附件，避免新增本地模型导致整表 Schema 准入失败。
