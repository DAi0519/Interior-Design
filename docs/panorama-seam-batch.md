# 全景批量修缝

整图优化 → 横向循环平移半幅 → 全图中央透明遮罩修缝 → 将原生回包循环平移半幅，复原经度。

优化使用项目现有的默认全景美化提示词。本地保存本批实际提示词及 SHA，再用同一份正文处理所有图片。第一段默认 Seedream 5.5 的 2:1 2K，返回 2880×1440 PNG。第二段把整张平移图和同尺寸的中央透明 PNG 遮罩送到 GPT Image 2.6 Sunburst 的同步遮罩编辑接口。提示词让模型只修接缝断点和可见的明暗、颜色过渡，保留原有结构、物件、材质和连续线条。

循环平移只交换两半的列，首尾接缝准确落到中央。最终 `final.png` 直接使用回包的 RGB 与透明度，原样恢复经度。同尺寸回包才能逆移，尺寸不符的样本会停在复原阶段。批次记录中的 `restoreMode` 为 `direct-inverse`。遮罩限定模型编辑请求中的区域，回包也可能改动罩外。报告以首段优化图为基准记录罩外 RGB 和 alpha 差异，供出图后复核。

历史三景的两组新词实测中，直接逆移结果有 99.77%–99.99% 的罩外像素存在 RGB 差异。更早的回包还出现过罩外 alpha 变化。相同接缝位置和对面区域可在[三景实测对照](../outputs/panorama-centered-seam-prompt-20261125/inverse-comparison/report.html)查看。

## 批量运行

从项目根目录执行：

```sh
node --env-file-if-exists=.env.local scripts/panorama-seam-batch.mjs \
  --input "/absolute/input" --output "/absolute/result"
```

输入目录读当前层的 PNG、JPEG 和 WebP，输入必须是 2:1 单帧。也可使用 `--manifest /absolute/list.json`，清单为含 `path` 与可选 `name` 的数组，相对路径按清单目录解释。

可选参数：

- `--optimizer` 选择支持 2:1 2K 的项目三方模型键，默认 `seedream55`。
- `--mask-width` 指定成图上的全高透明列数，默认按输出宽度的 128/2880 取整。
- `--repair-prompt` 从本地文本读取第二段提示词。可以保留同一输出目录，复用首段成图、居中输入和遮罩，单独复测新词。
- `--max-new-requests` 限制本次新模型请求数。两段各占一次。填 0 可复用已有有效回包并重新逆移。

同一输出目录内，提交前按输入、参数及提示词冻结身份。匹配的历史原生回包和回执可直接复用。改变遮罩宽度或第二段提示词会创建新遮罩阶段并复用同身份的优化原件。已提交且没有完整回包的阶段会保留状态，核对失败回执后方可安排新尝试。处理失败会进入逐图报告，其余图片继续。首段、居中图、实际透明罩、原生回包、复原全景及回执都进入批次目录。

## 验收

输出目录的 `report.html` 提供优化底图和最终全景 PNG，以及亮度、色度和罩外差异记录。用 360° 查看器在同一视角切换两版，可沿接缝检查天花、墙面和地面，再转向场景其余部分复核物体、材质和光影。

本地链路测试见 `node --test scripts/panorama-seam-batch.test.mjs`。五张新增实测和前三张复用结果可在[全景查看器](../outputs/panorama-seam-direct-batch-20261125/viewer/index.html)中同视角切换。
