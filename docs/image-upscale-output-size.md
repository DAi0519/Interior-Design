# 图片超分输出尺寸

在生图工作台的“AI编辑 → 图片超分”或“Beta跑图 → AI超分”选择工作流，再选择输出尺寸。

| 工作流 | 输出尺寸选项 |
| --- | --- |
| 攸行3B、7B·1MP、7B·0.75MP、拆分版7B | 4K、6K、8K |
| KS版·7B、KS直入·7B | 原图2倍、4K、6K |

“原图2倍”把真实原图宽、高分别乘2。4K以长边4096px为目标，6K以长边6144px为目标；短边按原图比例计算并对齐偶数，不裁剪或强拉画幅。以1600×900原图为例，三档目标分别为3200×1800、4096×2304、6144×3456。最终PNG的真实尺寸单独回读，不把请求目标当作实际结果。

## 输入与推理

两套KS输入仍要求宽、高各384–3200px。KS版保留0.75MP前置预处理，KS直入继续让原图直接进入7B；选择4K或6K只改变输出目标，不新增一次输入预缩放，也不改变模型、色彩或噪声参数。不得用后置插值补齐图片并冒称模型直接生成该分辨率。

2X的SeedVR2短边目标仍为原图短边×2，`max_resolution=0`。4K/6K的短边目标取等比计算值，`max_resolution`为4096/6144。长边模式的运行元数据不写`outputScale=2`；请求目标尺寸、源图尺寸与实际产物尺寸分别记录。

## Beta混选与历史兼容

Beta整批使用一个输出尺寸，选项取所选工作流支持项的交集：只选KS时可用原图2倍/4K/6K，只选普通工作流时可用4K/6K/8K，混选时可用4K/6K。选择6K时每个候选均提交6K，不再把KS暗改成2X。

明确保存的合法4K/6K选择保留；KS单独选择且缺失或损坏尺寸时回退原图2倍，普通或混选回退4K。主工作台从8K切到KS时回退原图2倍。已建档批次继续使用冻结档位，历史2X归档仍可恢复。

工作流键与原始来源SHA保持不变，KS两套执行版本为`2026-10-21.1`。显示名称去掉固定“两倍”；飞书历史单选标签作为已有归档身份保留，实际输出模式由配置快照及生成参数明确记录。`workflows/`内的原始JSON不回写，因此独立导入的原图两倍画布仍按其原合同运行。

## 验收边界

自动化覆盖目标几何、节点参数、输入原字节、UI交集与记忆、请求和产物元数据，以及新长边归档与旧2X恢复。运行时需同时核验主工作台和Beta目录。GPU实际执行、6K显存、最终像素尺寸、画质及耗时另以真实任务验证，自动化或目录可选不代表这些已通过。
