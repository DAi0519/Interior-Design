# AI扩图：选择结果，调整构图

从AI编辑分组进入AI扩图。用户上传图片，选择画幅比例，再拖动原图决定位置，拖动四角调整原图大小。Flux、Qwen和Sunburst统一固定2K输出，不提供1K或4K分辨率选项；默认原比例及1.5倍扩图范围，点击生成后才提交模型任务。

页面不再提供四边像素输入，也不要求用户处理8、16或32像素对齐。原图移动和缩放均不会改变最终画布、画幅选中态或分辨率。

## Beta批量工作流对比

从Beta跑图选择AI扩图，可直接选择飞书中其他功能创建的图片样本集，不需重新上传。样本集的功能仅记录创建归属，新建时归当前功能；已有集合和原样本ID保持不变，复用不复制记录、不重传原件。图片与纯提示词输入仍区分，运行时按当前功能校验真实原图。扩图工作流支持多选Flux Fill OneReward、Flux Fill Dev、Qwen Image Edit 2511和Sunburst，默认选择OneReward与Qwen；目录显示各项可用状态与原因，失效的已选项必须手动取消或修复，不能静默替换。

整批共用画幅和扩图倍率，默认原比例与1.5倍，另有1:1、4:3、16:9、3:4、9:16及2/3倍；每张原图默认居中，输出固定2K且不提供分辨率选项。原比例按各样本真实宽高计算，不把整批套成首张图片的比例；各工作流继续遵循自身的输入、对齐及输出合同。该入口用于同批样本比较工作流，不提供逐图拖动构图；需手动调整单图位置时使用生图工作台的构图预览。

扩图工作流、画幅与倍率独立保存，不覆盖普通功能的模型和参数。普通Prompt、Agent、设计、质量和分辨率控件在扩图模式下隐藏。每个样本分别运行所有已选工作流，复用现有队列和生成/同步双进度；超限Sunburst原图自动等比缩小，超宽画幅保全图补边。手动RETRY保留已成功项，只补失败图或失败同步；ComfyUI工作流根据自身可用状态准入，Sunburst另需当前Key权限。

批次输入使用稳定样本ID及`outpaintWorkflowKey`，构图为`outpaintCanvas={ratio,resolution:"2K",position:{x:0.5,y:0.5},scale:1/倍率}`。服务端逐项读取原图并调用正式扩图服务，版本、真实尺寸、实际Prompt与结果只归档独立Beta“跑图明细”，不回退写入旧生成记录。只有附件与字段回读成功后才显示已同步及结果预览。此入口的接入和合同验证不代表真实批次、速度或扩图画质已验收。

## 扩图模型

Flux Fill提供当前环境中的两款兼容模型：默认Flux Fill OneReward（FP8）和Flux Fill Dev（原版）。选择器直接呈现，切换时保留画幅和构图，输出仍固定2K；悬停可查看完整权重文件名，结果卡和执行元数据保留本次实际模型。

服务端分别验证候选的节点、文件与权重格式；默认模型缺失时仍可使用原版。已选模型失效时阻断，不能悄悄改用其他模型。Qwen Image Edit 2511使用独立ComfyUI工作流，Sunburst使用独立API模型；这两者均不显示或消费Flux选择。

## 自动场景提示词

Qwen当前版本为`2026-10-20.1`：Janus仍只分析未扩边源图，既有Qwen专用question及seed/temperature/top_p/max_new_tokens不变。Janus生成的动态正文原文直连`SaveText.text`，再由其输出进入正向编码`positive.prompt`；不再拼固定前缀或`Scene continuation`，执行图不含`QWEN_OUTPAINT_PROMPT`和`StringConcatenate`。约1MP推理、latent遮罩、整图恢复且不回贴的策略不变。

同次History实际返回的`SaveText`原文才写入「最终 Prompt」；缺失时仍留空并标未捕获。此次只改变Prompt链路，不据此宣称灰色画布、接缝或多场景画质已经修复。

**历史实现（2026-10-19.3，以下三段为当时链路记录，不用于当前配置）：**

Qwen `2026-10-19.3`接入Flux已有的Janus-Pro-1B模型及节点。Janus只分析提交给工作流的未扩边源图，独立ComfyUI导入图直接分析上传原图，不读取补灰后的扩图画布。沿用固定seed `298596445848600`、temperature `0.1`、top_p `0.95`、max_new_tokens `999`，以Qwen专用分析问题生成英文场景续写描述。

固定`QWEN_OUTPAINT_PROMPT`约束在前，Janus场景描述在后，经原生`StringConcatenate`拼接，再由`SaveText`保存并透传完整正文至Qwen正向编码。接入提示词链不改变约1MP推理、latent遮罩或不回贴原图的输出策略；请求里的用户Prompt和采样字段不能覆盖固定分析配置。独立图需要`JanusModelLoader`和`JanusImageUnderstanding`，沿用现有Flux环境的Janus依赖；文本拼接与保存使用原生节点。

Flux `2026-10-19.1`同样增加`SaveText`正文保存与透传，保持原来的Janus问题、模型和采样参数。Qwen保存固定约束与场景描述的合成全文，Flux保存Janus生成并实际传入编码器的全文；两者均从同次History捕获，不能依据节点存在或固定约束推断执行正文。

## 输出与原图

工作台的Flux Fill与Qwen固定以2048px长边为目标；Flux按8px网格，Qwen按16px网格和预设画幅落位；原比例从真实源图尺寸计算，短边就近对齐模型网格，不裁切原图或套用近似预设。Sunburst预设使用其模型自身2K档的合法画幅矩阵；原比例采用长边2048与短边就近16px对齐，超宽或超高源图保留完整内容，将目标短边补到满足3:1的最小16px网格，目标同时满足16px对齐/655360–8294400像素/边长不超过3840的接口合同，不能静默换成最近预设；页面只读显示各引擎实际请求的输出宽高。更改画幅、模型、原图位置或大小都不会改变2K输出档位。

Flux和Qwen仍接收最长边4096px以内的原图；Sunburst原图保护上限为16384px且仍受单图8MB约束，服务先按目标2K画布等比缩小，再对实际提交图执行3840px输入上限校验。超3:1原比例不裁剪或拉伸内容，只补足目标短边；原始/实际源尺寸、请求/实际画幅和补边事实均写入生成参数。允许上传4K源图与提供4K结果是两个独立合同。

原图大小相对于目标画布内等比适配的最大尺寸计算，允许真实缩小或放大；原图大小提供1.5倍、2倍、3倍扩图范围与连续大小调节。最大尺寸对应适配1倍，最小通常对应扩图3倍；模型的最小输入尺寸可能限制进一步缩小。放大通过等比重采样，不会凭空恢复原图细节。Flux继续使用原有LayerStyle预处理，因此可能轻微缩放或裁切。Sunburst的mask表达编辑意图，模型仍可能重绘原图区域。

省略缩放字段的旧请求仍保留原图不放大、必要时缩小或同画幅缩至约90%的兼容行为。显式选择最大原图且完全填满同画幅画布时仍可预览，生成前提示缩小原图以留出扩图区域。

Qwen使用2511 FP8mixed及专属Lightning 4步。先按构图生成目标画布，整张画布与遮罩统一到约1024²像素、8px对齐的工作尺度，条件参考与采样latent使用同一工作图，避免高分辨率采样与内部参考缩放不一致。原图区域仍通过latent噪声遮罩约束，内侧32px目标像素参与接缝过渡；最终保存完整解码图并通过Lanczos恢复精确目标大小，不再把高分辨率原图贴回去，避免合成重新引入矩形色差。原图区域仍经过VAE与重采样，色调、纹理和细节可能变化，不能承诺逐像素保留。工作台2K表示最终输出尺寸，恢复尺寸使用插值，没有接入AI超分模型，也不代表原生2K推理。推理宽高、恢复方式、非像素保真策略和实际输出分别归档。

系统记录原始源图尺寸、是否重采样、原图相对大小及真实提交/输出尺寸。2K尺寸合同与预览成功不等于模型质量通过。

## 构图操作

侧栏选择工作流、模型和画幅，不显示分辨率选择；主区域展示目标2K画布，棋盘格区域表示待补全范围，底部只显示输出宽高、原图大小与居中操作；比例沿用侧栏选择，不重复回显，操作说明保留在画布的可访问描述中。页签用文字区分当前视图，不显示选中底色、描边或下划线；原图只保留四角手柄，键盘操作仍有局部焦点提示。没有结果时隐藏无效的结果页签。桌面画布随可用空间适配横竖比例，窄屏改为上下布局。

上传或替换有效原图后默认回到构图预览。“构图预览 / 生成结果”可来回切换，保留已生成图片、下载和飞书链接；旧任务恢复、轮询、完成或失败均不覆盖新上传图片的构图。新START按任务身份解除新图预览保护，正常显示生成进度、完成结果或失败重试；这些视图切换不重新生成。

- 鼠标或触屏拖动原图，位置始终限制在目标画布内。
- 拖动原图四个角等比缩放，到上限或下限显示提示；聚焦角点后也能使用键盘调整大小。
- 画布下方“原图大小”提供1.5倍、2倍、3倍快捷选择和原图大小滑杆。自由缩放不匹配预设时显示“自定义”。
- 居中只恢复位置，保留当前大小；换图恢复默认1.5倍与居中构图。
- 聚焦画布后，用方向键微调；Shift加方向键作较大移动。
- 点击“居中”或按Home恢复中心位置。
- 比例单选支持方向键、Home与End。

## 实现边界

public/image-outpaint-workspace.js在扩图控制器绑定后移动原画布节点，保留拖动、触屏、键盘和居中事件；只切换预览与结果的容器可见性，不复制或销毁结果DOM；隐藏构图时统一关闭原图大小浮层，避免切换功能或任务状态后残留。任务控制器的忙碌通知同步当前阶段、任务ID与创建时间，区分旧任务与新START；组合层只在有效新源变化时通知工作区，同图重绘不会抢走用户页签。

public/image-outpaint-transform.js负责浮点视觉规划outpaintVisualPlan、四角鼠标/触屏/键盘缩放、倍率快捷选择、原图大小滑杆与边界提示。预览始终保持原图比例及亚像素位置，四角固定对角锚点并直接计算边界，不调用模型的整数/ceil32规划，不提供吸附或缓动追赶。手势高频坐标仅保留最新值，每帧局部绘制一次；图片布局尺寸保持最大适配基准，每帧仅更新translate3d与scale，操作柄独立定位以保持固定点击区域。移动/缩放时不刷新模型、单选、错误、输出说明或读取图片src。松手与重绘继续使用同一视觉几何，校验和提交前结算末坐标；换图、切参数、隐藏预览、失焦或取消会清除失效帧。

public/image-outpaint-geometry.js是浏览器与服务端共同使用的执行几何真源；输入目标比例、分辨率、归一化位置、可选scale和引擎能力，输出目标画布、等比重采样、预处理尺寸与整数四边扩展；outpaintScaleBounds给出合法相对大小边界。连续预览不使用执行整数四边，防止细微操作被取整冻结、Flux每32px跳格或松手回弹。

新页面提交outpaintCanvas={ratio,resolution,position,scale}，其中resolution固定为`2K`，另有Flux专属outpaintModel稳定键。服务端在outpaintCanvas省略resolution时补为`2K`，显式提交`1K`或`4K`均拒绝，不静默改成2K。scale是相对目标最大适配尺寸的原图比例，范围通常为1/3至1，扩图倍率为1/scale。服务端在真实图片字节与EXIF方向归一后重新计算，按各引擎规则执行等比重采样、预处理及整数落位；预览与实际输入可能有该引擎像素网格范围内的差异，不能信任客户端四边计算或伪造宽高。

旧expansion请求只保留2K输出兼容：Flux和Qwen实际目标长边必须为2048px，Sunburst目标必须属于其模型自身2K画幅矩阵，或满足长边2048/16px对齐/比例不超过3:1的原比例2K尺寸。旧请求若算出1K、4K或其他档位，在收费调用前拒绝，不改写四边或尺寸冒充原请求。旧任务与历史结果仍按原档位和实际尺寸展示，不回写成2K。

拖动只改变留白分配：left+right始终等于target.width-prepared.width，top+bottom始终等于target.height-prepared.height。像素取整集中在共享几何，不允许四边单独取整后改变输出尺寸。

## 验证

合同测试覆盖三引擎固定2K、resolution省略默认/显式其他档位拒绝、旧expansion的2K准入、原图输入限值、目标尺寸固定、拖动边界、缩放边界/实际重采样与非法输入；浏览器检查无分辨率选项、选择/预览/键盘/触屏与桌面/窄屏布局。连续性测试用三引擎100帧0.1/0.2px移动与缩放轨迹验证零冻结、原图比例、固定对角及松手无回弹，并检查4K源图布局宽高在手势期间固定。帧调度与浏览器采样不代表所有设备的稳定帧率。真实生成另行检查下载图片实际尺寸、产物身份和扩展质量，自动化检查不消耗模型额度。

Qwen独立可导入JSON位于 `workflows/Qwen-Image-Edit-2511-Outpaint.json`，API图位于同目录的 `.api.json`；执行 `node scripts/export-qwen-outpaint.mjs` 从运行真源重新导出。当前`2026-10-20.1`运行图25个节点、独立图26个节点，Janus动态正文直连SaveText/positive，不拼固定前缀或Scene continuation；独立图增加原生上传和约0.39MP/16px等比预处理，LoRA匹配当前独立导入环境的同版FP32，并显式保存flow采样选项（工作台仍使用BF16），Janus仍直接读取上传原图。独立图是底层手工工作流，输出由原生预处理与扩边节点决定，默认示例1024×768不属于工作台产品档位；工作台固定2K限制由服务执行，不声称导入JSON自动锁定2K。动态INT尺寸控件链接保留数值占位`0`，STRING控件链接保留空字符串占位，`SaveText.text`使用强制输入端口，Janus seed控件为`fixed`。
