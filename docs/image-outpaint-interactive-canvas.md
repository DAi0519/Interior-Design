# AI扩图：选择结果，调整构图

从AI编辑分组进入AI扩图。用户上传图片，选择画幅比例和扩图分辨率，再拖动原图决定位置，拖动四角调整原图大小。默认16:9、2K及1.5倍扩图范围；点击生成后才提交模型任务。

页面不再提供四边像素输入，也不要求用户处理8、16或32像素对齐。原图移动和缩放均不会改变最终画布、画幅选中态或分辨率。

## 扩图模型

Flux Fill提供当前环境中的两款兼容模型：默认Flux Fill OneReward（FP8）和Flux Fill Dev（原版）。选择器直接呈现，切换时保留画幅、分辨率和构图；悬停可查看完整权重文件名，结果卡和执行元数据保留本次实际模型。

服务端分别验证候选的节点、文件与权重格式；默认模型缺失时仍可使用原版。已选模型失效时阻断，不能悄悄改用其他模型。Qwen Image Edit 2511使用独立ComfyUI工作流，Sunburst使用独立API模型；这两者均不显示或消费Flux选择。

## 输出与原图

Flux Fill与Qwen的1K/2K/4K分别以1024/2048/4096长边为目标；Flux按8px网格，Qwen按16px网格和精确画幅落位。Sunburst按其模型公开的合法画幅/档位矩阵计算，不能用Flux尺寸替代；页面只读显示各引擎实际请求的输出宽高。

原图大小相对于目标画布内等比适配的最大尺寸计算，允许真实缩小或放大；原图大小提供1.5倍、2倍、3倍扩图范围与连续大小调节。最大尺寸对应适配1倍，最小通常对应扩图3倍；模型的最小输入尺寸可能限制进一步缩小。放大通过等比重采样，不会凭空恢复原图细节。Flux继续使用原有LayerStyle预处理，因此可能轻微缩放或裁切。Sunburst的mask表达编辑意图，模型仍可能重绘原图区域。

省略缩放字段的旧请求仍保留原图不放大、必要时缩小或同画幅缩至约90%的兼容行为。显式选择最大原图且完全填满同画幅画布时仍可预览，生成前提示缩小原图以留出扩图区域。

Qwen使用2511 FP8mixed及专属Lightning 4步。先按构图生成目标画布，整张画布与遮罩统一到约1024²像素、8px对齐的工作尺度，条件参考与采样latent使用同一工作图，避免直接2K/4K采样与内部参考缩放不一致。解码后通过Lanczos恢复精确目标大小，再按原高分辨率遮罩合成原图中心；原图内侧32px为接缝带，其余中心保留。2K/4K表示最终输出尺寸，恢复尺寸使用插值，没有接入AI超分模型，也不代表原生2K/4K推理。推理宽高、恢复方式和实际输出分别归档。

系统记录原始源图尺寸、是否重采样、原图相对大小及真实提交/输出尺寸。选择分辨率和预览成功不等于模型质量通过。

## 构图操作

侧栏选择工作流、模型、画幅和分辨率，主区域展示目标画布；棋盘格区域表示待补全范围，底部只显示输出宽高、原图大小与居中操作；比例沿用侧栏选择，不重复回显，操作说明保留在画布的可访问描述中。页签用文字区分当前视图，不显示选中底色、描边或下划线；原图只保留四角手柄，键盘操作仍有局部焦点提示。没有结果时隐藏无效的结果页签。桌面画布随可用空间适配横竖比例，窄屏改为上下布局。

上传或替换有效原图后默认回到构图预览。“构图预览 / 生成结果”可来回切换，保留已生成图片、下载和飞书链接；旧任务恢复、轮询、完成或失败均不覆盖新上传图片的构图。新START按任务身份解除新图预览保护，正常显示生成进度、完成结果或失败重试；这些视图切换不重新生成。

- 鼠标或触屏拖动原图，位置始终限制在目标画布内。
- 拖动原图四个角等比缩放，到上限或下限显示提示；聚焦角点后也能使用键盘调整大小。
- 画布下方“原图大小”提供1.5倍、2倍、3倍快捷选择和原图大小滑杆。自由缩放不匹配预设时显示“自定义”。
- 居中只恢复位置，保留当前大小；换图恢复默认1.5倍与居中构图。
- 聚焦画布后，用方向键微调；Shift加方向键作较大移动。
- 点击“居中”或按Home恢复中心位置。
- 比例和分辨率单选支持方向键、Home与End。

## 实现边界

public/image-outpaint-workspace.js在扩图控制器绑定后移动原画布节点，保留拖动、触屏、键盘和居中事件；只切换预览与结果的容器可见性，不复制或销毁结果DOM；隐藏构图时统一关闭原图大小浮层，避免切换功能或任务状态后残留。任务控制器的忙碌通知同步当前阶段、任务ID与创建时间，区分旧任务与新START；组合层只在有效新源变化时通知工作区，同图重绘不会抢走用户页签。

public/image-outpaint-transform.js负责浮点视觉规划outpaintVisualPlan、四角鼠标/触屏/键盘缩放、倍率快捷选择、原图大小滑杆与边界提示。预览始终保持原图比例及亚像素位置，四角固定对角锚点并直接计算边界，不调用模型的整数/ceil32规划，不提供吸附或缓动追赶。手势高频坐标仅保留最新值，每帧局部绘制一次；图片布局尺寸保持最大适配基准，每帧仅更新translate3d与scale，操作柄独立定位以保持固定点击区域。移动/缩放时不刷新模型、单选、错误、输出说明或读取图片src。松手与重绘继续使用同一视觉几何，校验和提交前结算末坐标；换图、切参数、隐藏预览、失焦或取消会清除失效帧。

public/image-outpaint-geometry.js是浏览器与服务端共同使用的执行几何真源；输入目标比例、分辨率、归一化位置、可选scale和引擎能力，输出目标画布、等比重采样、预处理尺寸与整数四边扩展；outpaintScaleBounds给出合法相对大小边界。连续预览不使用执行整数四边，防止细微操作被取整冻结、Flux每32px跳格或松手回弹。

新页面提交outpaintCanvas={ratio,resolution,position,scale}和Flux专属outpaintModel稳定键。scale是相对目标最大适配尺寸的原图比例，范围通常为1/3至1，扩图倍率为1/scale。服务端在真实图片字节与EXIF方向归一后重新计算，按各引擎规则执行等比重采样、预处理及整数落位；预览与实际输入可能有该引擎像素网格范围内的差异，不能信任客户端四边计算或伪造宽高。旧expansion请求仍兼容且严格校验。

拖动只改变留白分配：left+right始终等于target.width-prepared.width，top+bottom始终等于target.height-prepared.height。像素取整集中在共享几何，不允许四边单独取整后改变输出尺寸。

## 验证

合同测试覆盖引擎合法档位、目标尺寸固定、拖动边界、缩放边界/实际重采样、非法输入与旧接口兼容；浏览器检查选择/预览/键盘/触屏与桌面/窄屏布局。连续性测试用三引擎100帧0.1/0.2px移动与缩放轨迹验证零冻结、原图比例、固定对角及松手无回弹，并检查4K源图布局宽高在手势期间固定。帧调度与浏览器采样不代表所有设备的稳定帧率。真实生成另行检查下载图片实际尺寸、产物身份和扩展质量，自动化检查不消耗模型额度。

Qwen独立可导入JSON位于 `workflows/Qwen-Image-Edit-2511-Outpaint.json`，API图位于同目录的 `.api.json`；执行 `node scripts/export-qwen-outpaint.mjs` 从运行真源重新导出。独立图增加原生上传和约0.39MP/16px等比预处理，工作台仍按用户所选目标分辨率精确计算。

2026-10-19 同一864×1184夜景客厅、3:4/2K/1.5倍构图实跑，约888×1184推理后输出1536×2048，执行66.984秒；扣除32px接缝后932×1301原图中心逐像素相同，原失败图的窗框/吊灯/沙发矩形错位在该样本消失。证据位于 `.impeccable/review/qwen-outpaint-alignment/`。这是单场景验证，未新增4K实跑，也不代表多场景稳定性。

2026-10-15 Qwen首张真实GPU验证为768×512输入、1024×768输出，执行138.668秒；扣除32px内侧接缝带后的704×448中心逐像素相同，详见 `.impeccable/review/qwen-outpaint/validation.json`。2K/4K已通过尺寸准入，未实测GPU性能。

## 飞书归档

三引擎扩图均在生成前检查飞书生成记录字段、功能与模型选项。真实尺寸通过后，复用现有异步同步调度写入原图、结果图、AI扩图功能、实际模型、构图及工作流参数；结果卡显示同步中、已同步或失败，并提供飞书记录链接。图片超分继续保留仅本机路径。

Qwen与Sunburst的最终Prompt从执行真源生成；Flux的Janus内部正文当前未返回时留空并注明来源。参数未捕获时不得编造；历史结果可从已保存的真实原图与成品补写，不重新调用GPU。
